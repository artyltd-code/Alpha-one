# Alpha One

Alpha One 是一個簡單的台股持股損益 Web App。

## 目前功能

- 新增持股
- 輸入股數、平均成本、目前價格
- 自動計算總成本、總市值、損益、報酬率
- 按一下自動更新台股目前價格
- 匯出 / 匯入資料備份
- 資料存在使用者自己的瀏覽器 localStorage

## GitHub Pages 使用方式

1. 將 ZIP 解壓縮。
2. 到 GitHub 的 `alpha-one` repository。
3. 點 `Add file` → `Upload files`。
4. 上傳解壓縮後資料夾裡的所有檔案。
5. 點 `Commit changes`。
6. 到 `Settings` → `Pages`。
7. Source 選 `Deploy from a branch`。
8. Branch 選 `main`，資料夾選 `/root`。
9. 儲存後等待 GitHub Pages 產生網址。
