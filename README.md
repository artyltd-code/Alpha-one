# Alpha One v2.0.0

Alpha One 是台股持股損益 Web App。

## 這版功能

- 新增持股
- 修改股數、成本、現價
- 自動計算總成本、總市值、損益、報酬率
- 按一下更新台股目前價格
- 匯出 / 匯入備份
- 手機版介面
- 可部署到 GitHub Pages

## 上傳方式

把此 ZIP 解壓縮後的所有內容上傳到 GitHub `alpha-one` 倉庫根目錄。

需要上傳：

- index.html
- manifest.json
- sw.js
- css 資料夾
- js 資料夾
- assets 資料夾
- README.md
